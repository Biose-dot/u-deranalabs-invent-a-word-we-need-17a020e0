# Invent a Word We Need

One brand-new word with a one-line definition, 111 characters.

> callhearse — rehearsing a phone call word for word in your head, then still opening with 'uh' when they answer.

**The word:** *callhearse* — *call* + *rehearse*, with a nod to *hearse* (the solemn vehicle: a call rehearsed like a funeral). A noun/verb for the meticulous mental rehearsal everyone does before dialling — and the way it collapses the second someone picks up.

**Why it fills a real gap:** English has no word for pre-call rehearsal, a daily ritual for millions, and the definition lands in a single reading: the preparation, then the punchline.
